# Changelog

## 0.1.3

- Fixed extension icon not displaying.
- Fixed JMeter HTTP headers not being captured in results.
- Reworked run/stop/clear buttons in the Test Plans view.
- Added recent runs history with delete support.
- Results are preserved and re-displayed after a window reload.

## 0.1.2

- Bug fixes and improvements to test plan discovery.
- Improved error messages when JMeter is not found.

## 0.1.1

- Initial release of JMeter Copilot.
- Run JMeter test plans from the sidebar or VS Code Chat.
- Inspect results, failures, and sample details with Copilot chat tools.
- Auto-discovery of `.jmx` files in the workspace.
